# LifeCounterByTMB

LifeCounter by The Magical Brick.

Lebenspunkte-Zähler für Commander-Runden, gedacht für den NFC-Tag im Commander-Rahmen der Deckbox „The Magical Brick“.

- 2–6 Spieler, jedes Feld zu seinem Sitzplatz gedreht (Handy liegt in der Tischmitte)
- Tippen links −1, rechts +1, Halten zählt weiter
- Commander-Schaden je Gegner (auch Partner), Gift, Commander-Steuer, Energie, Erfahrung, Monarch, Initiative
- Würfel (W6, W20), Münze, Startspieler, Rückgängig, Bildschirm anlassen
- Läuft komplett im Browser, auch offline; der Spielstand bleibt nur auf dem Gerät

Optional per Adresse: `?spieler=4&leben=40`
